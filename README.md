# Jpga Gift Hub

Estrutura organizada do site:

- `index.html` — estrutura e textos da página
- `css/style.css` — todo o visual/CSS
- `js/app.js` — interações e demonstração do chat
- `assets/images/` — imagens do site
- `assets/audio/` — áudios do site

## Como atualizar no GitHub

Substitua/adicione os arquivos mantendo as mesmas pastas.

Se usar GitHub Pages, o `index.html` continua sendo o arquivo principal.
